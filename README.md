# TautoLab

O **TautoLab** é uma aplicação web educacional desenvolvida para auxiliar no aprendizado de conceitos de teoria dos conjuntos e lógica proposicional por meio de conteúdos explicativos, exercícios interativos e simuladores matemáticos.

## Funcionalidades

- **Aprender:** apresenta conceitos de teoria dos conjuntos, proposições lógicas, conectivos e quantificadores.
- **Exercícios:** permite praticar os conteúdos por meio de questões interativas.
- **Simulador de conjuntos:** permite realizar operações entre conjuntos e visualizar os resultados em um diagrama de Venn.
- **Simulador de tabela-verdade:** permite gerar tabelas-verdade para expressões lógicas e identificar tautologias, contradições e contingências.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Figma (prototipação da interface)

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `aprender.html` em um navegador.

Não é necessário configurar um servidor ou banco de dados para utilizar a aplicação, considerando a estrutura atual do projeto.

## Objetivo acadêmico

O projeto foi desenvolvido no contexto da disciplina de **Modelagem e Simulação Matemática**, com o objetivo de relacionar conceitos matemáticos e lógicos à construção de algoritmos e aplicações interativas.

## Equipe

Projeto desenvolvido em grupo como atividade acadêmica do curso de Ciência da Computação.
