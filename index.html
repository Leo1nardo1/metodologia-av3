Fundamentos

Aprenda os conceitos básicos de conjuntos e lógica matemática.

Um conjunto é uma coleção bem-definida de objetos, chamados de elementos. Geralmente representamos conjuntos por letras maiúsculas (A, B, C) e seus elementos entre chaves.

Exemplo: O conjunto das vogais.

V = {a, e, i, o, u}

Tipos de Conjuntos:
  • Unitário: Possui apenas um elemento. Ex: {2} ou A = {Lua}.
  • Vazio: Não possui elementos. Representado por ∅ ou { }.
  • Infinito: Possui infinitos elementos. Ex: Conjunto dos números naturais ℕ = {0, 1, 2, 3, ...}.
  • Finito: Possui uma quantidade limitada de elementos. Ex: A = {1, 2, 3} ou os dias da semana.

Imagine uma caixa de lápis de cor 🖍️. A caixa é o conjunto e cada lápis é um elemento.

Vamos chamar a nossa caixa de C = {vermelho, azul, verde}

∈ "pertence" 📦
Responde: "Este lápis está dentro da caixa?"
vermelho ∈ C → o lápis vermelho está na caixa. ✅
rosa ∉ C → o lápis rosa não está na caixa. ❌

Agora imagine uma caixa pequena dentro de uma caixa maior, como as bonecas russas 🪆.

Veja: A = {1, 2} e B = {1, 2, 3, 4}

⊂ "está contido" 🪆
Todo mundo de A também está em B. Por isso a caixa A cabe dentro da caixa B.
A ⊂ B → "A está contido em B". ✅
B ⊃ A → o contrário: "B contém A".
💡 Como não se confundir?
  • ∈ liga um objeto a uma caixa (um lápis → a caixa).
  • ⊂ liga uma caixa a outra caixa.

Nem toda frase é uma proposição. Uma proposição é uma sentença declarativa que pode ser classificada como Verdadeira (V) ou Falsa (F), nunca os dois ao mesmo tempo.

É proposição (tem valor V ou F): ✅
  • "O Brasil fica na América do Sul." → Verdadeiro (V)
  • "2 + 2 = 5." → Falso (F)
  • "Salvador é a capital da Bahia." → Verdadeiro (V)
Não é proposição (não dá para julgar V ou F): ❌
  • "Qual é o seu nome?" (Pergunta)
  • "Estude para a prova!" (Ordem / Imperativo)
  • "x + 2 = 5" (Sentença aberta — não sabemos quem é o x)

Os conectivos servem para combinar proposições simples e formar proposições compostas.

Conectivo Símbolo Nome Exemplo prático
NÃO ¬ ou ~ Negação Inverte o valor: "Não está chovendo."
E ∧ Conjunção Só é V se tudo for V: "Estudo e treino."
OU ∨ Disjunção Basta um ser V: "Leio ou jogo."
SE... ENTÃO → Condicional Promessa: "Se chover, então molha."
SE E SOMENTE SE ↔ Bicondicional Valores iguais: "Passo se e somente se estudar."

Os quantificadores são palavrinhas mágicas que dizem quantos elementos têm uma característica.

Imagine uma turma com 3 crianças: Ana, Beto, Caio 🧑‍🤝‍🧑

∀ "para todo" (vale para TODOS) 📣
"Todo mundo trouxe lanche." Só é verdade se as 3 crianças trouxerem.
Com números: ∀x ∈ {2, 4, 6}, x é par ✅ verdade, todos são pares!
Já ∀x ∈ {2, 4, 5}, x é par ❌ falso, porque o 5 não é par.
∃ "existe" (basta UM) 🔎
"Alguém trouxe lanche." Basta uma criança ter trazido.
Com números: ∃x ∈ {1, 2, 3}, x > 2 ✅ verdade, o 3 é maior que 2!
💡 Para lembrar:
  • ∀ (de cabeça para baixo, parece um A de "All", "todos") é exigente: todos precisam passar no teste.
  • ∃ (um E ao contrário, de "Existe") é tranquilo: basta um passar.

Considere dois grupos de amigos: A = {1, 2, 3} e B = {3, 4, 5}.

União (A ∪ B) — "Juntar tudo" 🤝
Reúne todos os elementos de A e de B em uma única caixa, sem repetir o que aparece duas vezes.
Exemplo: A ∪ B = {1, 2, 3, 4, 5}
Interseção (A ∩ B) — "O que têm em comum" 🎯
Pega somente os elementos repetidos que estão nos dois conjuntos ao mesmo tempo.
Exemplo: A ∩ B = {3} (se não houver nada em comum, o resultado é ∅).

Considere o Universo U = {1, 2, 3, 4, 5, 6}, A = {1, 2, 3} e B = {3, 4}.

Diferença (A − B) — "Só o que é de A" ✂️
Tira de A tudo o que também aparece em B.
Exemplo: A − B = {1, 2} (o 3 saiu porque estava em B).
Complemento (A̅) — "O que falta para completar U" 🧩
São todos os elementos do Universo (U) que ficaram de fora de A.
Exemplo: A̅ = {4, 5, 6}

Quando montamos a tabela-verdade completa de uma expressão, o resultado final recebe um nome especial:

  • Tautologia: O resultado é sempre Verdadeiro (V) em todas as linhas. Ex: p ∨ ¬p ("Ou chove, ou não chove").
  • Contradição: O resultado é sempre Falso (F) em todas as linhas. Ex: p ∧ ¬p ("Chove e não chove ao mesmo tempo").
  • Contingência: Mistura resultados V e F dependendo dos valores iniciais. Ex: p → q.

Duas expressões são equivalentes (≡) quando possuem exatamente a mesma tabela-verdade:

🔄 As 3 regras de ouro:
  • Dupla Negação: ¬(¬p) ≡ p (Negar duas vezes volta ao início).
  • Leis de De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q e ¬(p ∨ q) ≡ ¬p ∧ ¬q.
  • Equivalência do "Se... então": p → q ≡ ¬p ∨ q ("Se estudo, passo" equivale a "Não estudo ou passo").
