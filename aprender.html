MÓDULO 1

Fundamentos

Aprenda os conceitos básicos de conjuntos e lógica matemática.

Um conjunto é uma coleção de objetos, chamados de elementos. Geralmente representamos conjuntos por letras maiúsculas (A, B, C) e seus elementos entre chaves.

Exemplo: O conjunto das vogais.

V = {a, e, i, o, u}
Tipos de Conjuntos:
  • Unitário: Possui apenas um elemento. Ex: {2}.
  • Vazio: Não possui elementos. Representado por ∅ ou { }.
  • Infinito: Possui infinitos elementos. Ex: Conjunto dos números naturais (N).

Estes são os símbolos que usamos para relacionar elementos e conjuntos.

Pertinência (∈ / ∉): Relaciona um elemento a um conjunto.
Ex: a ∈ V (a pertence a V) ou b ∉ V (b não pertence a V).
Inclusão (⊂ / ⊃): Relaciona um conjunto a outro conjunto.
Ex: Se A = {1, 2} e B = {1, 2, 3, 4}, então A ⊂ B (A está contido em B).

Nem toda frase é uma proposição. Uma proposição é uma sentença declarativa que pode ser classificada como Verdadeira (V) ou Falsa (F).

  • É proposição: "O Brasil fica na América do Sul." (V)
  • É proposição: "2 + 2 = 5." (F)
  • Não é proposição: "Qual é o seu nome?" (Pergunta)
  • Não é proposição: "Estude para a prova!" (Imperativo)

Os conectivos servem para combinar proposições simples e formar proposições compostas.

Conectivo Símbolo Nome
NÃO ~ Negação
E ∧ Conjunção
OU ∨ Disjunção
SE... ENTÃO → Condicional
SE E SOMENTE SE ↔ Bicondicional

*Na próxima aba (Simulador), você poderá testar como esses conectivos funcionam na prática.

Usados para generalizar proposições.

  • Universal (∀): "Para todo". Ex: ∀x, x + 0 = x (Para todo x, x mais zero é igual a x).
  • Existencial (∃): "Existe pelo menos um". Ex: ∃x, x > 10 (Existe pelo menos um x que é maior que 10).
